# Shelly’s photo uploads

This folder is reserved for approved, original photos only. The site currently uses labelled placeholders; adding a file alone does not activate it. Set both `src` and descriptive `alt` for its slot in `src/content.mjs`, then rebuild.

Do not put unapproved portraits, community-event photos, private data or source-document photos here. Everything under `public/` is copied into the deployable `dist/` output.
